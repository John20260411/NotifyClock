# 通知闹钟（NotiAlarm）

监听微信、QQ、哈工大 APP 等任意 App 的通知，识别出里面的时间，自动创建提醒：
到点前按你设定的提前量（比如 60、10、0 分钟）响铃、振动、弹窗。

## 安装

1. 把 `app/build/outputs/apk/debug/app-debug.apk` 发到手机（微信文件传输助手、QQ、数据线都行），点开安装。
   提示“未知来源”时允许安装。
2. 打开“通知闹钟”，把首页“权限”一栏里的每一项都点“去开启”：
   - **通知使用权**：必须开启，否则读不到其他 App 的通知
   - **发送通知**、**精确闹钟**、**全屏弹窗**
   - **忽略电池优化**
3. 进入“设置”，勾选要监听的 App（默认已勾选微信、QQ、TIM；名字里带“哈工大/工大/HIT”的 App 也会自动勾选）。

### 国产手机一定要做的额外设置

小米/华为/OPPO/vivo 等系统会在后台杀掉 App，导致通知监听失效、闹钟不响：

- **自启动**：设置 → 应用 → 通知闹钟 → 允许自启动
- **后台运行**：省电策略改为“无限制”（小米）、“允许后台活动”（华为“应用启动管理”里改为手动管理并全部打开）
- 在最近任务里把“通知闹钟”**锁定**（下拉卡片或长按加锁）
- 微信、QQ 本身的通知要打开，且最好开启“通知显示消息详情”，否则通知里只有“你收到一条消息”

## 识别方式

| 模式 | 说明 |
| --- | --- |
| 规则优先（默认） | 先用本地规则解析；规则识别不了、但消息里像是有时间时，才调用大模型 |
| 大模型优先 | 像是有时间的消息都交给大模型，失败再用规则 |
| 只用规则 | 完全离线 |

本地规则能识别：`明天下午3点`、`今晚7点半`、`下周三上午10点半`、`周五`、`11月5日 23:59`、
`2026-11-10 14:00`、`11/8 18:30`、`5号`、`大后天`、`30分钟后`、`两个半小时后`、`三点一刻` 等。
只有日期或只有时间时，消息里还要有“开会、考试、作业、截止、上课、集合…”之类的事件词，避免闲聊误报。

大模型使用 OpenAI 兼容接口，在设置里填写：

| 服务 | 接口地址 | 模型名 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |

注意：开启大模型后，含时间的通知原文会发送给对应服务商。

## 使用

- 识别到时间后会**直接创建**提醒，同时弹一条“已创建提醒”的通知，可以点“撤销”或“修改”。
- 首页“试一试”可以粘贴一段文字测试识别效果；“最近处理的通知”能看到每条通知的识别结果。
- 每个提醒可以单独修改时间和提前量（逗号分隔的分钟数，最多 9 个）。
- 到点时弹出确认窗口：点“知道了”，或选择延后 5/10/30/60 分钟（可在设置里改，也能在弹窗里自定义）。
  返回键关不掉弹窗，必须做出选择。亮屏时弹窗需要“显示在其他应用上层”权限（小米还要“后台弹出界面”）。
- 铃声和振动默认持续 5 分钟，可改为 1–30 分钟或“一直响到确认”。超时没确认会停止响铃，但弹窗保留，并留下一条带“延后”按钮的通知。
- 铃声可选系统铃声或手机里的音乐文件；音量可跟随“闹钟音量”或“媒体音量”。
- 免打扰时段（如 23:00–07:30）：落在时段里的提前提醒，事件还没开始就改到时段结束时响，
  事件本身在时段里（如早上 6 点出发）就改到睡前时段开始时响；“准时”那次默认照常响，可关闭。
  每个提醒在首页会显示实际的响铃时刻。

## 自己编译

需要 JDK 17 和 Android SDK（platform 34）。用 Android Studio 打开本目录即可；或命令行：

```bash
./gradlew assembleDebug        # 生成 APK
./gradlew testDebugUnitTest    # 运行时间解析的单元测试
```

## 代码结构

```
app/src/main/java/cn/notialarm/
├── NotifyListener.kt        通知监听服务
├── Processor.kt             通知 → 解析 → 创建提醒
├── Reminders.kt             提醒增删改 + 时间格式化
├── Notifier.kt              所有通知（已创建 / 闹钟弹窗 / 未处理）
├── parse/TimeParser.kt      本地中文时间解析规则
├── parse/LlmParser.kt       大模型解析
├── alarm/AlarmScheduler.kt  用 AlarmManager 排闹钟
├── alarm/AlarmService.kt    响铃 + 振动（前台服务）
├── alarm/Receivers.kt       闹钟触发 / 开机重排 / 撤销
├── data/                    设置、提醒存储、日志
└── ui/                      首页、设置页、全屏闹钟页
```
